\subsection{Goals}

% \Khang{Kết hợp với RAG là phụ, cốt lõi là invent ra được improvement của multimodal retrieval}
\noindent The primary goal of this project is to research, design, implement and evaluate aBridgeAI, an intelligent LMS that bridges the gap between theoretical knowledge acquisition and practical career readiness. To achieve this aim, the project focuses on the following objectives:

\begin{itemize}
    \item \textbf{Developing a Smart Content Ingestion and Retrieval Pipeline:} To engineer an automated system capable of processing multimodal educational materials. The system will transcribe, extract, and index these materials into a vector database for subsequent retrieval tasks.
    
    \item \textbf{Developing an Adaptive Theoretical Assessment Module:} To build an AI-driven quiz generation engine that dynamically creates context-specific questions based strictly on the ingested curriculum. This goal includes designing an adaptive feedback loop that directs struggling students back to precise timestamps or document sections for targeted remediation.
    
    \item \textbf{Providing Students with a Context-Aware Mock Interview System:} To build a conversational AI interviewer utilizing LLMs and Retrieval-Augmented Generation (RAG). The core innovation lies in dynamically generating technical and behavioral interview scenarios strictly grounded in both the teacher's specific lecture content and the student's personal resume, ensuring an authentic and highly relevant practical assessment.
    
    \item \textbf{Constructing a Comprehensive Analytics and Gap-Reporting Engine:} To develop an automated evaluation rubric that assesses technical accuracy, communication clarity, and problem-solving skills. The system will synthesize data from both the learning loop (quizzes) and the application loop (interviews) to generate a personalized "Gap Report," highlighting discrepancies between theoretical knowledge and practical articulation.
\end{itemize}
