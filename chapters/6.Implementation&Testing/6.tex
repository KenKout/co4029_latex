\section{Implementation}
\label{sec:implementation}

This chapter describes the concrete implementation of the aBridgeAI backend, covering the development environment, project structure, and the realisation of each major subsystem. The implementation follows a feature-first architecture in which each domain (identity, courses, materials, quizzes, interviews, spaced repetition) is a self-contained package exposing its own models, queries, services, and API routers. Cross-cutting concerns — caching, audit logging, observability, and access control — are isolated in a shared \texttt{core} layer consumed by all features.
